# Support

Use GitHub Issues for reproducible bugs and focused feature proposals. Before opening an issue:

1. Confirm the problem occurs on the latest `main` branch.
2. Check existing issues for a duplicate.
3. Record browser, operating system, PHP version, GD status, source image format, and reproduction steps.
4. Remove private screenshots and notes from any attachment.

Security concerns must follow [SECURITY.md](SECURITY.md) and should not be reported publicly.
