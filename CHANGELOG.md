# Changelog

All notable changes to Design Reference Picker are documented here.

## 1.0.0 - 2026-07-31

### Added

- Screenshot discovery and natural sorting.
- Previous and next navigation with a current-image counter.
- Full screenshot approval into the handpicked collection.
- Two-point crop selection for the current image.
- Dragging and resize handles for precise adjustment.
- Scroll-safe coordinate conversion to original source pixels.
- PHP GD original-resolution cropping with browser Canvas fallback.
- Sequential JPEG crop naming and optional sequential note files.
- Explicit crop save and cancellation controls.
- High-visibility full-image crosshair and dark outside mask.
- Responsive footer toolbars, polished controls, and interaction feedback.
- English installation, usage, architecture, security, contribution, and support documentation.
- Automated validation and static documentation deployment workflows.

### Changed

- Renamed full-image selection to **APPROVE**.
- Renamed crop activation to **CUT** and active-state action to **CANCEL**.
- Reserved Enter for multi-line notes and moved crop confirmation to an in-selection button.
- Standardized vivid crop and success colors.
